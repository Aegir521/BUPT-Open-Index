# BUPT Open Index · 北邮开源与学习资源索引

一个由社区维护的北京邮电大学相关资源入口，从课程资料起步，逐步整理科研项目、学生项目、校园工具、竞赛资源和数据集。

本项目为非官方索引，不代表北京邮电大学或任何学院、教师、团队。我们整理原始链接和简短说明，不镜像原仓库，不搬运课程资料或代码；收录不代表原作者参与维护本索引，也不构成学校认可或质量背书。

欢迎各学院、各年级的同学参与，共同补充课程学习、校园生活与学术写作等资源。现有条目仍有限，不代表已经覆盖全校。

## 收录规则

1. **有明确关联。** 资源内容面向北邮课程或校园，或项目公开页面说明作者、团队、论文与北邮有关。提供可直接查看的来源；仅有名称缩写或“我认识作者”不足以证明关联。
2. **优先原始来源。** 优先链接原作者仓库或项目主页。二次整理、镜像或分支应说明来源及收录理由，避免同一资源重复占位。
3. **说明准确克制。** 用一两句话说明用途和分类，不编造覆盖范围、适用年级、维护状态、功能或作者身份。未知信息直接标为待核实；默认不记录易变化的 Star 数，也不以热度排序。
4. **区分公开与开源。** 公开可访问不等于具有开源许可。明确采用开源许可的项目可标注其许可；学习资料和指南可以只作为链接收录，但授权不清时必须注明，不称为已确认开源。
5. **尊重来源和权利。** 不在本仓库上传无授权课件、教材、试卷、付费资料、他人作业、个人信息或访问凭据。课程与竞赛资源的分享须符合相应教学和赛事规则。
6. **保持可维护。** 每项资源选择一个主分类；需要时用子分类补充。已失效或有争议的条目注明情况并复核，必要时移除；有明确错误时及时更正。

阅读课程参考项目应服务于理解和自主实现，请勿直接作为自己的作业或竞赛成果提交。

## 如何贡献

- 推荐资源：在本仓库的 **Issues → New issue** 中使用资源模板，提交链接、分类、简介、北邮关联依据和许可信息。
- 直接补充：Fork 本仓库，在对应章节新增条目，按 [CONTRIBUTING.md](CONTRIBUTING.md) 提交 Pull Request。
- 更正与移除：通过 Issue 或 Pull Request 提供条目链接、问题说明和可公开的依据；涉及隐私时不要在公开讨论中附上敏感信息。

只修改索引内容，无需下载外部项目，也无需搭建运行环境。

## 文件组织与扩展
